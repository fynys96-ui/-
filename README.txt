# جرد البخور — نسخة أولية قابلة للتثبيت

## محتويات الحزمة
- `index.html`, `app.js`, `styles` داخل الصفحة: واجهة عربية للموبايل.
- `products.json`: 105 صنفًا مستوردًا من ملف الجرد الأصلي.
- `manifest.json` و`sw.js`: لتثبيت التطبيق وتشغيله بعد تحميل الملفات عند استضافته عبر HTTPS.

## التشغيل والتثبيت على أندرويد
1. ارفع محتويات هذا المجلد كما هي إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify). لا ترفع ملف ZIP نفسه بدل الملفات.
2. افتح رابط `index.html` في Chrome على الهاتف.
3. من قائمة Chrome اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4. افتح التطبيق وسجّل الأسعار الفعلية. صدّر نسخة JSON احتياطية دوريًا.

## ملاحظات مهمة
- البيانات محفوظة محليًا داخل المتصفح/التطبيق؛ لا توجد مزامنة بين الأجهزة في هذه النسخة.
- ملف الجرد الأصلي لم يتضمن أسعار شراء وبيع، فتم بدء الأسعار بصفر.
- تصدير Excel ينشئ ملف `.xls` مبنيًا على جدول HTML، ويمكن فتحه في Excel. الاستيراد يدعم CSV UTF-8، وملفات HTML/Excel التي يصدرها التطبيق، ونسخ JSON الاحتياطية. لاستيراد `.xlsx` مباشرة، افتحه في Excel/Google Sheets واحفظه CSV UTF-8 أولًا.
- لا تخلط وحدات الصنف؛ الكمية تُحسب بالوحدة المكتوبة للصنف (مثلاً دستة أو قطعة). «عدد القطع» حُفظ كحقل مستقل كما في ملفك.
- نسخة أولية للاستخدام التجريبي؛ جرّبها على بعض الأصناف وتأكد من النتائج قبل الاعتماد عليها كدفتر المحل الوحيد.
